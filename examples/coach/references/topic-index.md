## 何时读本文件

当用户问题需要定位到具体框架分片时，先读本表；不要一次性加载所有分片。

| 用户问题 / 意图 | 读取文件 |
| --- | --- |
| 重力问题与可设计的真问题 / 当用户说「我卡住了」「不知道该不该换方向」时触发。 | `references/framework-01.md` |
| 一问一答的追问节奏 / 当一次对话出现多个待答问题、或用户开始疲惫时触发。 | `references/framework-02.md` |
| 工作观与人生观的一致性检查 / 当用户说「说不上来哪里不对」「总觉得别扭」时触发。 | `references/framework-03.md` |
| 能量地图：擅长与热爱的分离 / 当用户说「我也不知道自己喜欢什么」时触发。 | `references/framework-04.md` |
| 重新定义锚问题 / 当用户反复回到同一个无解方案时触发。 | `references/framework-05.md` |
| 三个平等的奥德赛计划 / 当用户说「帮我规划未来五年」时触发。 | `references/framework-06.md` |
