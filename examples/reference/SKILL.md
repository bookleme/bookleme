# 人生设计练习册（合成）·框架速查

## 核心定位

本技能把《人生设计练习册（合成）》中可复用的方法编译成「框架速查」流程，供你在真实问题里反复调用。它是结构化衍生笔记，不含原书段落，也不是原书替代品。适用于 查阅框架, 书中怎么讲, 术语出处, 章节速查 等场景；不适用于书中未覆盖的问题，以及需要专业资质判断的心理、医疗、法律、投资场景。

---

## 触发场景

- 当用户说「查阅框架」或提出相关问题时
- 当用户说「书中怎么讲」或提出相关问题时
- 当用户说「术语出处」或提出相关问题时
- 当用户说「章节速查」或提出相关问题时

---

## 工作流

### Step 1：确认适用条件

检查用户请求是否落在触发场景内，并确认书中确实覆盖该问题。若数据或用户陈述不足，先追问，不用假设填充。

### Step 2：定位框架

读取 `references/topic-index.md` 找到对应分片；按 Topic Index 路由到对应 references/ 分片，只加载当前问题需要的那一份。

### Step 3：按框架执行

按分片中的 1-2-3 步骤执行，并保留作者的精确命名；每条判断都要带上处。

### Step 4：产出具名结果并声明边界

按「输出格式」给出带板块的结果，显式写出不适用条件与「还需要哪些数据」。

### Step 5：遇到书中未覆盖的问题

明确回答「书里没讲」并说明能力边界，不编造章节、出处或结论。若属于心理/医疗/法律/投资等专业判断，提示寻求有资质的专业人士。

---

## 输出格式

框架速查答复 的必备板块：
命中的框架 / 带出处的规则 / 执行步骤 / 不适用边界 / 出处清单

输出必须带出处；书中未涉及的问题必须写「书里没讲」。


示例结构：

```
## 框架速查答复
- 命中的框架：（名称 + 出处）
- 带出处的规则：（When X, do Y, because Z）
- 执行步骤：1. … 2. … 3. …
- 不适用边界：…
- 出处清单：segment_id / char_range
```

---

## Gotchas

- 遇到书中未回答的问题，必须明确回答「书里没讲」并说明边界，不得编造出处。
- 不得把整书文本塞进 SKILL.md；只在需要时按相对路径读取 references/ 下的分片。
- 每条框架与断言必须带出处（segment_id + char_range），保留作者的精确命名。
- 不得复制原文段落；单条引文 ≤150 字且可逐字追溯。
- 回答要写「何时用 / 怎么用 / 什么时候不适用」，不写读书报告式摘要。
- 反模式：无出处的断言。
- 反模式：没有 Topic Index 路由表，导致每次都全量加载。
- 反模式：把 full_text.txt 或 slices/ 打进产物包。
- 反模式：把「书里没讲」的问题硬编一个答案。
- 书中未涉及的问题必须回答「书里没讲」，不得编造出处；这不是能力缺陷而是忠实度要求。
- 版权：本技能是《人生设计练习册（合成）》的结构化衍生笔记，不含原书段落，非原书替代品；版权与商标归原权利人所有。仅供学习，支持正版。
- 数据依赖：不绑定任何专有数据库；出处来自本地有权文件与标注可信度的公开资料。
- 错误路径：无法定位框架或证据不足时，回到 Step 1 追问，不要硬套框架。
